This project creates machine-generated personal-name attestation indexes from Latin inscription corpora. It is a derived, computational resource by Michael A Bosse — not an official release of EDCS, LIRE, EDH, Trismegistos, CIL ACE, Ubi Erat Lupa, DARE, or any other source database.

Machine-generated annotations

The following are generated by this project's NLP pipeline and should be treated as scholarly aids requiring verification against the inscription text and relevant publications:

  • Name extraction and component classification (praenomen, nomen, cognomen)
  • Social-status labels, fragmentary flags, non-person flags
  • Heuristic name clusters (possible same-person groups)
  • English translations and summaries
Clusters are heuristic, not confirmed identities. A cluster groups inscriptions that may refer to the same individual based on name similarity and geographic proximity — not prosopographical verification.
